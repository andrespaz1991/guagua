Una palabra. Una diapositiva.

Prepara un juego para adivinar palabras o frases. Escribe tu lista, carga un CSV y descarga una presentación lista para proyectar.

1. Agrega las palabras

Separa las palabras con saltos de línea, comas o punto y coma. Para cambiar un tiempo, escribe palabra | segundos.

O carga un CSVSe sumará a la lista manual

CSV: una columna palabra o frase y, opcionalmente, segundos. Acepta coma, punto y coma o tabulación. Descargar ejemplo CSV.

2. Personaliza el juego

Al elegir una imagen se activará como fondo de todas las palabras. Para volver al color, cambia «Tipo de fondo» a «Color sólido». Acepta JPG, PNG y WebP.
